# Animal teammate avatar prompts (01–32)

These 32 static animal portraits were generated with the built-in `image_gen.imagegen` tool, one independent call per asset. No CLI/API fallback, stock assets, or code-drawn substitutes were used. Every call set `transparent_background: true` and omitted both reference-image mechanisms.

## Exact prompt set

For each numbered subject below, substitute the complete subject text for `{subject}` in this template. This reconstructs the exact prompt sent to the built-in tool.

```text
Use case: stylized-concept
Asset type: one static selectable teammate avatar for a web application.
Primary request: {subject}
Style/medium: authentic chunky 2D pixel art sprite on a 32–48 pixel source-grid, hard square pixel steps, simple limited colors, dark plum outline one pixel thick, sparse flat shading. Cozy playful game-character style, readable when displayed at 24, 48, and 64 pixels.
Composition/framing: one centered full-body character, frontal or slight three-quarter pose, fills about 78 percent of a square canvas, generous consistent transparent margin, silhouette entirely visible.
Scene/backdrop: genuinely transparent alpha background, no backdrop, no ground shadow.
Constraints: static idle pose, no animation, no text, no watermark, no extra characters, no decorative props, no gradients, no antialiasing, no fuzzy edges, no texture, no 3D render, no realistic fur. Crisp square pixels, clean silhouette. Produce a PNG asset.
```
